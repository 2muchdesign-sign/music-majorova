# Сайт музыкального руководителя О.А. Майоровой

Пересборка https://detkigou.wixsite.com/music: статический сайт из 8 страниц, без сборщиков и фреймворков.

## Идея
**Нотный стан.** Пять линий проходят через весь сайт и прорисовываются у заголовков разделов.
- Главная: на нотном стане можно сыграть ноты (до–до), есть кнопка «Сыграть гамму»; меню разделов сделано в виде клавиатуры пианино.
- «Праздники»: учебный год показан нотами на нотном стане.
- «Родителям»: загадки с отгадкой «по клику»; «Играем в оркестр» — ритмы из больших и маленьких фигур, их можно проиграть; свой ритм можно составить.
- Звук включается только по нажатию. Кнопка «Звук» в шапке добавляет звук клавишам при наведении.

## Структура
```
index.html … kontakty.html   готовые страницы (собраны скриптом)
assets/style.css             стили
assets/app.js                эффекты и интерактив (~10 КБ)
img/                         фото с исходного сайта
_build/pages/*.html          тексты страниц (правьте здесь)
_build/build.py              сборка: общий шапка/подвал + страницы
```

После правки текстов: `python3 _build/build.py` (из этой папки).

## Эффекты
- Весь текст есть в HTML, страница полностью читается без JavaScript.
- `prefers-reduced-motion` отключает всё движение.
- Отключить эффекты: в `_build/build.py` замените `data-effects="full"` на `lite` (без декоративного движения) или `off` (только лайтбокс, ритм и форма).

## Что осталось на исходном сайте
- «Основная рабочая программа» и «Цветные физкультминутки» на Wix встроены виджетом-просмотрщиком документов. Ссылки ведут на исходные страницы. Если пришлёте файлы, их можно положить прямо в сайт.
- Документы (сценарии, консультации) скачиваются с хранилища Wix — при удалении Wix-сайта их нужно перенести в папку `docs/`.
- Блок «Видео» на исходной странице пустой — видео на сайт не переносились.
